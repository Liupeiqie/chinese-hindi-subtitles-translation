# 待校对翻译初稿

此目录统一存放中文 → 印地语（天城文）的双语翻译初稿，供后续正式校对；不代表已定稿。

每个项目单独建目录，输出位置为：

```text
待校对翻译初稿/<项目名>/
  hi-zh.srt             印地语在上、中文在下的待校对初稿
  verification.json     该版初稿的结构核验报告
  translation-notes.md  翻译依据及待确认问题
```

翻译助手先完成 `projects/<项目名>/drafts/hi-zh.srt`，逐条自查并运行项目 `check`；通过后将该文件及项目 `reviews/` 下对应的报告、翻译记录复制到这里。交付前确认两个 SRT 的 SHA-256 相同，且等于报告中的 `candidate_sha256`。未通过核验的工作稿留在项目中修复，不作为待校对初稿交付。

当前脚本的 `check` 只核验项目工作稿，不自动导出；保存到本目录及核对副本由执行翻译的助手完成。交付时提供本目录中 SRT 的实际路径。

保存并核验完成后，助手将本次相关项目文件、这里的交付文件及术语维护记录提交到 Git，再向本仓库已配置的私有 GitHub 远端推送一次，并核对远端提交。此步骤已获用户授权，不需重复确认；不得混入无关修改、密钥或音视频。推送失败时如实说明，保留本地成果，不强制推送。同步到 GitHub 不代表正式定稿。

如在这里直接修改字幕，需先将修订稿同步回对应项目的 `drafts/hi-zh.srt`，再运行 `check` 并更新这里的报告和副本。不得继续使用旧报告；已有校对单时重新生成并校对。

同一项目重复交付时，先将旧交付文件保存在该项目子目录的 `history/<版本号>/` 下，再更新当前文件，避免丢失人工修改。正式定稿仍须用户明确要求并通过项目 `finalize`，输出位于项目 `final/`。
