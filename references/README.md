# 讲记、论释及其他参考资料

将可使用的资料放入 library/，并在 catalog.csv 登记稳定编号（例如 REF-001）、标题、作者/出处、版本、仓库相对路径、原始链接、页码/章节说明和备注。若只有链接，实际引用前须读取相应内容并登记所用版本；不要仅凭标题或摘要声称查阅了正文。

优先提供可检索的 UTF-8 txt/md。PDF、DOCX 等原件可存档；按需要提取文字，保留原件页码/章节和提取稿的对应关系。扫描件 OCR 结果须核对。工具只复制和校验参考文件，不自动解析、检索或理解这些文件。

项目 new 的 --reference 参数可重复使用，只传本次相关文件。建议同时传入 catalog.csv，冻结资料标题、版本与编号映射；原件和提取稿也可一起传入。项目内的副本和指纹用于复查当时所用依据，不会自动跟随中央资料更新。

引用格式：`REF-001，第3讲，p.12，段落2`；无页码时使用章节、段落号或稳定标题。每条关键消歧、术语新译或与现行术语冲突的决定，写入项目 reviews/translation-notes.md，注明字幕序号、依据位置、判断及未决问题。

参考资料帮助理解字幕；字幕原文仍是翻译对象。讲记与字幕不一致时不得补写、删改字幕原意或改动中文原文。术语表与可靠资料冲突时先记入 terminology/proposals.csv 和项目问题记录，核实后更新主表并同步工作项目。
