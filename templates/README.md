# 术语表

实际持续维护的主表位于 `terminology/glossary.csv`；这里的 glossary.csv 只是空白格式模板。使用 UTF-8 CSV，表头固定为 `source,target,note,reference`：

- `source`：中文词语，不能重复或为空。
- `target`：指定的印地语译法，不能为空。
- `note`：语境、禁用译法、专有名词说明等，可为空。
- `reference`：资料编号及页码/章节，或该术语的确认依据；未提供时留空，不编造出处。

包含逗号的字段用双引号包裹。仅有表头的空表是合法的，表示尚无指定术语。模板故意不预填可能不适用于课程的术语。

项目创建时复制术语表并记录指纹。主表更新后，现有工作项目通过 sync-inputs 显式同步，旧校对单会失效；已定稿项目另建版本。术语的词形变化是否合适由校对判断，脚本不以简单字符串匹配判定翻译质量。
