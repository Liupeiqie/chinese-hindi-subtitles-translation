# REF-KLDY02-002 《喇荣课诵集》开场顶礼偈

索达吉堪布编译，2023年12月版，〈释迦佛修法仪轨〉“再念诵”段。课诵写作“赞如白莲闻名不退转”，并列藏文“པད་དཀར་”（白莲）。字幕第2条的“自莲”据此按白莲理解；闻名者得不退转，后半句向本师顶礼。

同册〈药师佛名号〉将简称与“药师琉璃光如来”相连；〈药师佛心咒〉的梵语音写含 Bhaiṣajyaguru。第942条只说药师佛，采用主表《药师经》中的词干加 बुद्ध。
