# 校对指令

对照 source/zh.srt、glossary/glossary.csv 和 drafts/hi-zh.srt，逐条审校全部字幕，并参考 reviews/translation-notes.md（若存在）。

- 忠实度：有无误译、漏译、增译；否定、因果、程度和语气是否保留。
- 术语：指定译法和上下文是否一致，专有名词和词形是否合适。
- 参考资料：实际对照项目资料快照检查关键消歧和术语出处，引用位置是否准确，有无根据讲记擅自扩写字幕。资料缺失时确认是否影响判断；不影响的情况可在校对备注记录不适用，影响判断的情况必须保留为未解决问题。
- 印地语：语法、性数一致、敬语、自然度、标点是否正确。
- 数据：数字、单位、日期、引用是否准确。
- 可读性：译文是否适合在原时间范围内阅读、断行是否自然；如果无法在不改变原时间码的条件下解决，记录问题，禁止擅改时间码。
- 中文与结构：运行 check 并确认通过。

需要修改时仅改译文，重新运行 check，并以新文件名运行 review 生成校对单。填写实际校对人、带时区的 ISO 日期时间（例如 `2026-11-15T14:30:00+08:00`）和检查项，逐条记录问题：

```json
{"cue": "12", "description": "具体问题和修订依据", "status": "open"}
```

status 只用 open 或 resolved；解决后保留问题描述并改为 resolved。无问题时 issues 为空数组。检查项仅在实际检查完整份字幕后设为 true。任何未解决问题都不能定稿。

校对单中的 candidate_sha256、source_sha256、glossary_sha256 和 context_sha256 自动生成，禁止手工修改。它们绑定本次字幕、术语和资料版本；任一依据后续变化必须重新校对。需要说明不适用项时可添加 notes 字段。
