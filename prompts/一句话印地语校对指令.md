# 一句话印地语校对指令

**第一步（出报告）：**

> 对待校对翻译初稿目录下【项目名】的双语 SRT 进行一次字幕校对，校对时查阅项目下的翻译报告、术语表、讲记等相关文档，重点检查佛法法义及增译、漏译、错译问题，生成可编辑的校对报告：每个条目以字母加数字编号，表格预留空白的校对意见栏，修改前后的印地语用括号注明对应中文含义；报告先不保存到项目目录，确认后再修改。

**第二步（填完校对意见后）：**

> 按照校对报告修改【项目名】字幕，交付字幕按原文件名加语种和版本号命名（如 金刚经13-原画_hi-zh_v3.srt），把校对报告和逐条修改结果写入对应项目目录，核验通过后推送一次仓库。

使用时将【项目名】替换为 `待校对翻译初稿/` 下的目录名。在 Claude Code 中，这两句话会触发项目 skill [hindi-subtitle-proofread](../.claude/skills/hindi-subtitle-proofread/SKILL.md)，具体步骤、脚本和核验要求都在其中；其他助手可直接按该文件执行。

**推送前置条件：只有修订后的比对核验通过、交付副本与核验报告和校对单指纹一致、报告中的修改结果表与实际文件逐字一致，才允许推送；否则暂停并报告问题。**
