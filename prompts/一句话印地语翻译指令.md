# 一句话印地语翻译指令

请将【中文 SRT 路径】中的中文字幕翻译为印地语（天城文），遵循本仓库印地语 v5 翻译规范和中文—印地语项目术语表，参考相关讲记、论释，输出印地语在上、中文在下的双语 SRT，完整保留中文原文（含换行、空格和标点）、序号、时间码及字幕条数，完成后逐条自查并运行自动比对，通过后将待校对初稿保存到本仓库 `待校对翻译初稿/<项目名>/hi-zh.srt`，同时保存对应核验报告及未决问题记录，随后将本次相关文件提交到 Git 并向本仓库私有 GitHub 远端推送一次、确认同步成功，未经我明确要求不定稿。

使用时将【中文 SRT 路径】替换为实际文件路径；具体执行规则见 [翻译指令](translate.md)。

**推送前置条件：只有当前版本比对核验通过，且保存的初稿与核验报告指纹一致，才允许推送；否则立即暂停交付和推送，保留工作稿并报告问题，等待处理后重新核验通过再继续。**
